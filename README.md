## 🧠 Intent Recovery System

AI-assisted Android productivity system that detects distractions and helps users recover their original task using smart contextual recovery popups.

### ✨ Features
- Distraction Detection
- Accessibility Service Monitoring
- Smart Recovery Popup
- Continue Anyway Option
- Go Back to Previous Task
- Session Memory
- Focus Tracking
